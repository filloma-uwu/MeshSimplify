# PQSS Official Simplified-Mesh Baseline

> The full-query measurements below are retained for history. The canonical
> benchmark is now the fixed official-simplification scope documented in
> `SCOPED_COMPARISON.md`.

## Dataset Roles

The production real-scene benchmark builds `1.obj` through `23.obj` as the
base pool, calls `EndPool()`, and then appends `24.obj` and `26.obj` through
`37.obj`. The comparator therefore treats the latter set as workpieces.

The repository's `obj_simplified` directory changes only these base models:

Models `1`, `6-11`, and `21-23` are byte-identical. Every appended workpiece
is also byte-identical. The base pool falls from 627,190 to 90,233 input
triangles, an 85.6131% reduction.

Every changed OBJ says it was generated by MeshLab. Each changed result is one
watertight, winding-consistent connected mesh, while its source contains
hundreds or thousands of disconnected components. This is characteristic of
an outer wrapping/reconstruction operation rather than ordinary topology-
preserving QEM decimation. The repository does not record the filter name or
parameters, so the exact algorithm cannot be established from the files.

## Reproduced CPU Result

The result below uses the actual PQSS CPU implementation, `Optimized`, one
query thread, all 882,008 real-scene poses, and original appended workpieces.
The original and simplified pools were tested in the same process.

| Metric | Original | Official simplified | Change |
|---|---:|---:|---:|
| Base input triangles | 627,190 | 90,233 | -85.6131% |
| Base built triangles | 629,236 | 90,743 | -85.5789% |
| Base BV nodes | 1,258,449 | 181,463 | -85.5805% |
| Maximum base depth | 59 | 19 | -40 levels |
| Pool memory | 371,230,896 B | 56,422,632 B | -84.8012% |
| Query wall time | 251.1391 ms | 235.5455 ms | -6.2091% |
| BV tests | 2,594,432 | 2,510,298 | -3.2429% |
| Triangle tests | 140,359 | 136,054 | -3.0671% |
| Positive results | 16,557 | 16,605 | +48 |

Correctness relative to the original result is `TP=16,557`, `TN=865,403`,
`FP=48`, and `FN=0`. The false-positive rate is 0.00555%. All 48 false
positives involve simplified `19.obj`: 46 are against `1.obj`, and 2 are
against `8.obj`.

This query trace does not by itself certify strict geometric containment. It
only establishes that no false negative occurred in the supplied poses.

## Interpretation

The 85.6% face reduction produces only about 3% fewer primitive/BV tests.
`6.obj` versus workpiece `26.obj`, neither of which the official data changes,
accounts for 1,910,696 BV tests and 112,963 triangle tests. That single pair is
73.6% of all original BV tests and 80.5% of all original triangle tests.

The official simplified data is now the performance baseline. A new strict
outer, depth-8 proxy pool should satisfy all of these conditions:

1. certified containment and zero false negatives;
2. actual PQSS maximum depth at most 8;
3. fewer than 2,510,298 BV tests;
4. fewer than 136,054 triangle tests.

Query time and false-positive rate are secondary tie breakers. The current
depth-8 proxy has 2,075,940 BV tests, which beats the official baseline by
17.3030%, but has 182,707 triangle tests, which is 34.2901% worse. It therefore
does not yet beat the official simplified data overall.
