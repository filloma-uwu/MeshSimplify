## 3. 必须遵守的算法目标

1. 禁止按模型 ID、文件名、截图角色或手工坐标特判。
2. 所有模型使用同一二进制和相同选项。
3. false positives 可接受，false negatives 不可接受。
4. 删除任何责任面之前，必须证明代理并集仍完整覆盖其责任区域。
5. 误差约束是统一的单向 `proxy -> phase1` Hausdorff 距离上限。
6. Hausdorff 上限是可行性阈值，不是局部、累计或全局误差预算。
7. 每个候选都面对同一个上限；不同区域之间不分配或累加误差。
8. 最终目标是在全部覆盖和误差硬约束下，最小化最终 OBJ 的实际三角形数。
9. 实际三角形数必须在内部面删除、共面并集和最终三角化之后计算。
10. primitive count、QEM、Chamfer、目标压缩率、PQSS workload 都不能替代目标函数。
11. recognizer 只能提出候选，不能贪心消费或删除责任面。
12. exact、planar、curved、convex 和 enclosing 候选必须进入同一模型级搜索。
13. 共面的输出区域必须先做几何并集，再三角化；重合面和无意义内部边不能保留。
14. box 是六个 polygon surface，不是特殊最终图元。
15. 简单 n 边形必须无 Steiner 点地产生恰好 `n-2` 个三角形。
16. 所有算法、生成器、验证器和算法测试必须使用 C++。
17. 不允许商业许可依赖。
18. 每个模型内部只允许一个 CPU 线程；不同模型可以各用一个线程并行。

## 5. `boundary=0` 的准确含义

当前验证器证明的是抽象组合 halfedge：

- 每个三角形形成合法三边循环；
- 每条抽象边恰有两条方向相反的 halfedge；
- opposite 对称；
- 每个拓扑顶点只有一个面扇区；
- 面邻接只有一个组合连通分支；
- 抽象复形 Euler characteristic 为 2；
- 组合定向体积有限且为正。

它没有证明 halfedge 在三维空间中的嵌入是合法的。当前明确没有检查：

- 非邻接三角形自交；
- 共面重叠面；
- 几何 T-junction；
- 不同拓扑位置映射到同一几何位置形成的 pinch；
- 隐藏封口、折叠面或重合面造成的假闭合；
- 当前组合曲面是否真的是期望实体的唯一外表面。

因此：

`boundary_halfedges=0` 只表示抽象复形没有未配对边，不能解释为“视觉上没有洞口”或
“几何上一定是无自交实体外壳”。

视觉轮廓也不一定是 halfedge 边界：

- 平面和洞壁连接形成的折边可以没有边界；
- 盲孔的洞口轮廓没有边界，整个外表面仍可能是 genus 0、Euler 2；
- 贯穿孔的外表面同样没有边界，但 genus 1、Euler 0；
- 只有表面真正缺面时，才应出现未配对 halfedge。

如果截图中的结构确定是贯穿孔，而数据仍报告 `boundary=0, Euler=2`，则必须怀疑
自交、重合、折叠配对或隐藏封口。不能只凭当前验证结果判定它正确，也不能只凭截图
判定它一定是未配对边。

## 7. 第二阶段的五步算法

### 7.1 几何规范化：`SurfaceArrangement`

输入：冻结的 `phase1_halfedge.bin`。

处理：

1. 为全部阶段一三角形建立 BVH。
2. 使用稳健谓词检测非邻接三角形相交。
3. 分割所有相交线、T-junction 和部分共面重叠。
4. 对共面重叠区域建立二维 arrangement。
5. 合并真正相同的几何边，不能只比较原始顶点索引。
6. 保留每个原子片段到 phase1 face 的完整 provenance。
7. 从无穷远空间单元开始做外部分类。
8. 仅在空间单元证书证明后删除重合面或内部面。
9. 无法可靠分类的片段保留为 exact fallback，禁止猜测删除。
10. 从真正的 exposed surface 构建新的工作 halfedge；不得伪造 opposite。

建议数据结构：

```text
Phase1Reference
  immutable triangles
  original halfedge hints
  face provenance
  triangle BVH

SurfaceArrangement
  exact/snap-rounded vertices
  atomic face fragments
  geometric edge incidence
  intersection curves
  coplanar overlap regions
  spatial cells and outside labels
  fragment -> phase1 responsibility

WorkingSurface
  exposed geometric faces
  trustworthy local halfedge adjacency
  unresolved fragments marked exact-fallback-only
```

阶段二首先应为 model14 输出诊断图层：

- topological unpaired edges；
- geometric seams/T-junctions；
- non-adjacent triangle intersections；
- coplanar overlaps；
- feature/crease edges；
- classified exposed boundary。

这样才能确认截图中的圆圈究竟是特征边、盲孔、贯穿孔，还是几何假闭合。

### 7.2 统一候选生成

所有 recognizer 只生成候选，不改变共享责任：

1. exact fallback patch；
2. exact coplanar polygon union；
3. disk 和 annulus；
4. cylindrical band 和 conical band；
5. envelope-bounded edge collapse/flip/retriangulation；
6. convex hull、support polytope 和其他 enclosing candidate；
7. 多个 surface primitives 共同构成的闭合保守代理组。

每个候选必须记录：

```text
responsibility fragments
geometric support and parameters
interface signature
actual output surfaces
actual triangulation
coverage certificate
directed Hausdorff certificate
candidate conflicts
post-union triangle cost information
```

平面、圆柱、圆锥、凸包等 family 不能按顺序运行并消费面。它们必须为同一责任集合
提出竞争候选。

### 7.3 两类独立硬证书

覆盖证书：

- 证明候选实体或候选并集完整包含其全部 phase1 责任片段；
- 对凸代理，所有责任三角形顶点通过全部半空间即可证明整个三角形被包含；
- 对非凸代理并集，必须使用 arrangement/cell classification 或等价严格方法；
- 只比较总面积、包围盒或稀疏采样不能签发覆盖证书；
- 删除内部表面必须证明它不属于最终 union 的 exposed boundary；
- 未证明即保留 exact fallback。

误差证书：

```text
sup { distance(x, phase1_surface) | x in final_proxy_surface } <= epsilon
```

- 方向固定为 `proxy -> phase1`；
- 每个候选使用同一个用户上限；
- 不存在误差预算；
- 最终证书必须覆盖完整输出三角形内部，不能只测顶点；
- 解析圆曲面必须对实际三角化结果验收；
- disk、annulus、cylinder、cone 从最少离散段数开始增加，选择第一个通过者；
- 共面并集和最终 exposed-boundary 提取后必须再做完整终检。

### 7.4 模型级最少三角形搜索

建立 `SemanticCandidateGraph`：

```text
硬约束：
  每个责任片段至少被一个选中候选覆盖
  所有候选通过统一 Hausdorff 上限
  接口兼容
  不产生未经许可的外露内部面
  最终 union 通过完整覆盖审核

目标：
  minimize actual_triangle_count(
    triangulate(
      exposed_boundary(
        coplanar_union(selected_candidates))))
```

不能简单最小化候选自身三角形数之和，因为共面 union、重叠代理和内部面删除会产生
非加性代价。

推荐两层搜索：

1. 单个 planar/round patch 内部用 shortest path 或 dynamic programming 求最少边界点、
   最少圆周段数；
2. 模型级用 branch-and-bound 或 CP-SAT 风格的候选选择，并用 lazy constraint/精确
   重算处理 post-union 三角形代价。

exact fallback 提供初始可行上界。大模型采用 anytime search，持续保存当前最优可行解
和 lower bound；搜索未穷尽时必须报告 `best-known feasible` 和 gap，不能宣称全局最优。

### 7.5 最终规范化和三角化

对选中候选并集执行：

1. 删除经过证明的内部表面；
2. 对全部几何共面区域做二维 union；
3. 提取 exposed boundary；
4. 输出 polygon、disk、annulus、cylindrical band、conical band；
5. 简单 n 边形严格生成 `n-2` 个三角形且不加 Steiner 点；
6. 圆曲面使用已通过证书的最小分段数；
7. 写出普通 triangle OBJ；
8. 对最终 OBJ 重新运行完整覆盖和 directed Hausdorff 验收。

最终 OBJ 不要求全局 watertight 或 manifold。重叠的保守代理可以存在，但重合共面面、
已经证明为内部的表面和无意义内部边不得保留。
